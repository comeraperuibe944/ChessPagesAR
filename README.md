# ChessPagesAR

Jogo de xadrez em Realidade Aumentada no navegador com camera em tela cheia e controle por pincelada.

Acesse em https://comeraperuibe944.github.io/ChessPagesAR/

## Como jogar

1. Permita o acesso a camera ao abrir a pagina.
2. O sistema procura automaticamente um tabuleiro fisico na imagem ou permite jogar direto no tabuleiro virtual AR.
3. Junte a ponta do polegar com o indicador para fazer a pincelada.
4. Use a pincelada para segurar pecas, mover pelo tabuleiro, levar pecas capturadas para o cemiterio lateral e redimensionar o tabuleiro pelos cantos ou com as duas maos.
